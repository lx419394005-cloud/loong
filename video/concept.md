# 小方块 · 演绎视频最终方案

> 一句话：**让 Claude 和 Codex 走出对话框，真正用上你的电脑。**
> 主角：**小方块**。Claude 和 Codex 是“用它的人”。
> 规格：9:16 竖版，22.5 秒（128 BPM × 12 小节），小红书 / 抖音 / 视频号通用。
> 风格：卡点硬切 + 变速，**真实键盘声、鼠标声、微信提示音做鼓点**，小方块的灯光当主光源。

## 故事线

1. **悬念**：Claude 和 Codex 已经很能干，但它们的活都在一个窗口里。如果它们能走出对话框呢？（不直接说“做不到”，用画面暗示）
2. **破局**：小方块插上，它是一把真的键盘鼠标，AI 通过它就能像人一样操作电脑。
3. **证明**：我在外面跟 Claude 说一句，电脑远程解锁 → Claude 回微信 → Codex 刷小红书做调研 → 报告发回我微信。
4. **收尾**：干完自己锁屏，定格在小方块。

## 让小方块当主角的三条规则

- **每小节第一拍都是小方块的镜头**：灯亮、灯变色、微距，哪怕只有 0.2 秒
- **Agent 每下一条指令，小方块就闪一下蓝灯**：观众看到的因果是“它在动手”，而不是“AI 在软件里跑”
- **开头和结尾都停在小方块上**

## Agent 浮窗

从小节 4 开始，画面右上角常驻一个小浮窗，显示**现在是 Claude 还是 Codex 在用小方块**，以及这一拍的指令：

```
Claude ▸ 输入密码
Claude ▸ 打开 微信，回复「晚上 8 点前发你」
Codex  ▸ 打开 小红书，搜索「桌宠」
Codex  ▸ 整理前 10 篇爆款
```

每行指令落在一拍上，同一拍小方块闪蓝灯、屏幕上发生对应动作。Claude 和 Codex 用两种颜色区分（例如 Claude 暖橙、Codex 冷白）。

## 剪出三个版本

- **主片 22.5 秒**：完整 12 小节
- **预告 9 秒**：小节 2 → 3 → 6 → 7 → 12，只讲“走出对话框 → 小方块 → Claude 回微信、Codex 刷小红书”
- **循环 4 秒**：小节 3 的小方块亮灯 → 小节 5 的解锁，当封面动图

## 拍摄清单

- **小方块**：磨砂款（暗房间、拍灯效）、闪粉款（定帧、手持）
- **灯效**：固件加“演示模式”，能手动切绿 / 蓝 / 闪烁，方便卡节拍
- **录屏**：锁屏、解锁、微信、小红书、文档都单独 4K 录屏，后期合成；手机对屏幕拍会有摩尔纹
- **Agent 画面**：Claude 和 Codex 各真实跑一遍任务（Claude 回微信 + 发报告，Codex 小红书调研）并录屏；小节 1 用它们真实写代码的录屏，小节 2 的光标弹回用后期做
- **浮窗**：用剪映 / AE 做成统一样式的字幕条，Claude、Codex 两种颜色
- **微信**：用小号或找朋友配合，提前约好对话内容
- **小红书**：提前确认“桌宠”搜索结果里有几篇高赞笔记
- **手机画面**：在手机 Claude 里发指令、微信收到报告，各录一段
- **场景**：暗房间（家里）、地铁或咖啡店（你在外面）
- **音乐**：128 BPM 左右的电子 / future bass，先选好再剪；另录 30 秒真实的键盘、鼠标、回车、微信提示音

## 拍摄注意点

- **解锁**：只拍密码圆点，不露真实密码；手机和电脑用同款壁纸，看出是“我远程开我自己的电脑”
- **微信**：对方头像和昵称打码或用小号；只拍“替我回一条消息”，不拍群发、加好友、批量操作
- **小红书**：只拍浏览、搜索、看评论，不拍自动点赞、评论、关注；别人笔记的作者名和头像打码
- **Claude / Codex**：用真实录屏和文字名称表现“可接入”，不把它们的 logo 当成小方块的主视觉，不写“官方合作”“官方认证”
- 演示内容只用自己的文档和表格，别露真实邮箱、账号
