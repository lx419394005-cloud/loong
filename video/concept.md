# 小方块 · 演绎视频最终方案（无人出镜版）

> 一句话：**让 Claude 和 Codex 走出对话框，真正用上你的电脑。**
> 主角：**小方块**。Claude 和 Codex 是“用它的 AI”。全片**没有人出镜**，只有产品、屏幕和动态图形。
> 规格：9:16 竖版，22.5 秒（128 BPM × 12 小节），小红书 / 抖音 / 视频号通用。
> 风格：产品广告式的演绎片。暗色空间 + 小方块的灯光当主光源，卡点硬切 + 变速，**键盘声、鼠标声、微信提示音做鼓点**。

## 制作方式

| 素材 | 怎么做 |
|---|---|
| **小方块** | 推荐 **3D 渲染**：直接用打印用的模型文件导进 Blender，做磨砂半透明 / 闪粉两种材质 + 内部发光，镜头可以绕着飞、穿过外壳。不想做 3D 就用手机微距实拍产品（只拍产品，不拍手），黑布背景 + 转台 |
| **电脑** | 3D 的 MacBook 模型，屏幕贴上录屏；或者只做悬浮的屏幕窗口，不出现整台电脑 |
| **屏幕内容** | Claude、Codex、微信、小红书都用真实录屏，后期加速、放大局部 |
| **手机** | 悬浮的手机模型 / 手机外框，屏幕贴录屏，不出现手 |
| **“人不在家”** | 用空间表达：空椅子、窗外从白天到黑夜，或者一张城市地图上手机和家之间连一条光线 |
| **浮窗、字幕、光线** | AE / 剪映做动态图形 |

## 故事线

1. **悬念**：Claude 和 Codex 已经很能干，但它们的活都在一个窗口里。如果它们能走出对话框呢？（不直接说“做不到”，用画面暗示）
2. **破局**：小方块亮起。它是一把真的键盘鼠标，AI 通过它就能像人一样操作电脑。
3. **证明**：手机上跟 Claude 说一句 → 电脑远程解锁 → Claude 回微信 → Codex 刷小红书做调研 → 报告发回手机微信。
4. **收尾**：干完自己锁屏，定格在小方块。

## 让小方块当主角的三条规则

- **每小节第一拍都是小方块的镜头**：灯亮、灯变色、微距，哪怕只有 0.2 秒
- **Agent 每下一条指令，小方块就闪一下蓝灯，同时一道光从小方块沿 USB 线流向电脑**：观众看到的因果是“它在动手”
- **开头和结尾都停在小方块上**

## Agent 浮窗

从小节 4 开始，画面右上角常驻一个小浮窗，显示**现在是 Claude 还是 Codex 在用小方块**，以及这一拍的指令：

```
Claude ▸ 输入密码
Claude ▸ 打开 微信，回复「晚上 8 点前发你」
Codex  ▸ 打开 小红书，搜索「桌宠」
Codex  ▸ 整理前 10 篇爆款
```

每行指令落在一拍上。Claude 和 Codex 用两种颜色区分（例如 Claude 暖橙、Codex 冷白）。

## 分镜（128 BPM，29 秒，段落定义见 `film/timeline.json`）

节奏原则：前三个动作（远程解锁、回微信、刷小红书）每个给 2 小节、一镜到底；后面的报告、发回手机、混剪快速刷过。字幕每段只留一行。

| 段落 | 时间 | 画面 | 字幕 |
|---|---|---|---|
| 开场 | 0–1.9s | 夜里桌上的笔记本，屏幕里 Claude、Codex 在写代码 | Claude 和 Codex 很能干 |
| 走不出去 | 1.9–3.8s | 推进屏幕，Dock 图标一个个暗下去，光标碰到窗口边缘被弹回 | 如果它们能走出对话框？ |
| 亮相 | 3.8–5.6s | Blender：黑暗中小方块亮起绿灯，图标连线点亮 | **小方块** |
| 发指令 | 5.6–7.5s | 小方块闪一下 → 咖啡桌上的手机里给 Claude 发一句话 → 家里的笔记本和小方块收到 | 人在外面，发一句话 |
| **远程解锁（重点）** | 7.5–11.3s | 锁屏和小方块同框，密码每拍一位、小方块跟着闪；回车 = 配乐 drop，推进屏幕，绿色对勾 | **远程解锁** |
| 回微信 | 11.3–15.0s | 点开小王，“周报呢？” → 自己打字回复 → 发送 | 替你回微信 |
| 刷小红书 | 15.0–18.8s | 搜“桌宠” → 信息流 → 打开爆款笔记 → 逐条读评论 | 替你刷小红书做调研 |
| 快：报告 | 18.8–20.6s | 调研表成形，缩成文件发到文件传输助手 | 报告写好，发回手机 |
| 快：手机 | 20.6–21.6s | 手机锁屏弹出微信通知 | （同上） |
| 快：混剪 | 21.6–24.4s | Claude / Codex 每半拍轮换操作 6 个软件，中间穿插小方块闪灯 | Claude、Codex 都能用 |
| 完成 | 24.4–26.3s | 全部完成 → 自动锁屏 → 熄屏，黑暗里小方块蓝灯转绿 | 干完，自动锁屏 |
| 片尾 | 26.3–29.1s | Blender：两款小方块定帧 | 小方块｜给 AI 一双真的手 |

## 剪出三个版本

- **主片 29 秒**：完整版
- **预告约 10 秒**：亮相 → 远程解锁 → 回微信 → 片尾
- **循环 4 秒**：远程解锁那一段（密码一位位输入 → 回车解锁），当封面动图

## 素材清单

- **小方块**：打印用的模型文件（做 3D）；或者磨砂款、闪粉款实物各一，黑布 + 转台微距实拍
- **灯效参考**：实拍一段绿灯、蓝灯、闪烁的视频，给 3D 灯光对颜色；实拍的话固件加“演示模式”，能手动切灯
- **录屏**：锁屏、解锁、微信、小红书、文档都单独 4K 录屏
- **Agent 画面**：Claude 和 Codex 各真实跑一遍任务（Claude 回微信 + 发报告，Codex 小红书调研）并录屏；小节 1 用它们真实写代码的录屏，小节 2 的光标弹回用后期做
- **手机屏幕**：手机 Claude 里发指令、微信收到报告，各录一段屏幕
- **浮窗**：做成统一样式的动态字幕条，Claude、Codex 两种颜色
- **微信**：用小号，提前准备好对话内容
- **小红书**：提前确认“桌宠”搜索结果里有几篇高赞笔记
- **空镜**：城市夜景（可用素材库或 AI 生成），空房间、空椅子
- **音乐**：128 BPM 左右的电子 / future bass，先选好再剪；另录 30 秒真实的键盘、鼠标、回车、微信提示音

## 注意点

- **解锁**：只出现密码圆点，不露真实密码
- **微信**：对方头像和昵称打码或用小号；只演“替你回一条消息”，不演群发、加好友、批量操作
- **小红书**：只演浏览、搜索、看评论，不演自动点赞、评论、关注；别人笔记的作者名和头像打码
- **Claude / Codex**：用真实录屏和文字名称表现“可接入”，不把它们的 logo 当成小方块的主视觉，不写“官方合作”“官方认证”
- 演示内容只用自己的文档和表格，别露真实邮箱、账号
